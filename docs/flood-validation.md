# Jangwani flood layer: data gate

No flood extent or water depth is rendered in this release. The supplied brief asks for a connected flood simulation validated against observed extents; the repository does not yet contain a suitable elevation model, local rainfall/river boundary conditions, or observed flood polygons with dates and provenance.

Copernicus DEM GLO-30 is a 30 m digital surface model, which includes surface objects and is not by itself a surveyed urban ground-elevation model. It must not be treated as flood-ready Jangwani terrain without local vertical-error assessment. Any future scenario needs a documented water-level boundary, connected inundation analysis, dated observed extents for validation, and visible uncertainty notes.
